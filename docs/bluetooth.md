# 蓝牙外设

## 用法

- 入口在设置页的蓝牙卡片，点管理进入蓝牙管理页。
- 点添加设备，弹出浏览器自带的蓝牙选择器，选中设备完成配对。
- 配对后点连接，连上后进入设备详情控制台。
- 控制台支持枚举服务与特征、读值、写值、订阅通知。
- 常用操作可保存为具名指令，之后在控制台一键发送。
- 角色在聊天里能感知当前已连设备，可按指令名调用已保存指令。
- 断开或移除设备也在管理页操作，移除后需重新配对。

## 原理

- 基于 Web Bluetooth API，只走 BLE / GATT，不经过系统蓝牙配对。
- 请求设备时用 optionalServices 做配对白名单，声明后续要用的服务 UUID。
- 页面重载后的重连走 `getDevices` 取回已授权设备，不再弹选择器。
- 角色感知走 volatile prompt 块，只在有已连设备时注入当前设备与指令名。
- 感知受实时感知宫格开关控制，关掉后 prompt 不再注入设备信息。
- 角色操控走前台聊天的内置工具 `ble_send_command`，只能调已保存的具名指令。
- 工具执行的是用户预存的字节，不允许角色现场编造任意负载下发。

## 已知边界

- 桌面端 Chrome / Edge 可用，需要 HTTPS 或 localhost 安全上下文。
- iOS Safari 不支持 Web Bluetooth，安卓 WebView 同样不支持。
- 只支持 BLE，不支持经典蓝牙音频（耳机、音箱、车载免提等走不了）。
- 页面关掉连接即断，没有后台保持连接的路径。
- 切后台、锁屏、杀进程都可能断开，回来后需在管理页手动重连。
- 读/写特征报 SecurityError，多半是配对时缺服务 UUID，移除后补上再重新配对。
- 部分设备一次只接受一个 GATT 连接，浏览器连着时厂商 App 要先断开。
